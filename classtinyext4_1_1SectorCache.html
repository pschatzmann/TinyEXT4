Detailed Description

Small write back cache of 512 byte sectors with LRU replacement.

All file system metadata is accessed through byte offsets, so we never need a buffer of a full file system block (1-64 KB): this keeps the RAM use at count * 512 bytes, allocated with the Allocator (PSRAM if available). Bulk file data bypasses the cache for whole sectors.
