Detailed Description

ext2/ext3/ext4 file system without journaling.

Reading supports extents and the old block maps, htree directories (read linearly), 64bit, flex_bg, meta_bg and inline data. Writing needs the extents and filetype features; it keeps the metadata_csum / gdt_csum checksums up to date but does not write a journal: the file system must be clean (no journal recovery pending).

The RAM use is the sector cache (TINYEXT4_CACHE_SECTORS * 512 bytes) plus about 300 bytes per open File: no buffer of a full file system block is needed.
