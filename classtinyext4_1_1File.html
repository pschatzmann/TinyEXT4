Detailed Description

An open file or directory. On Arduino it is a Stream, so print(), println(), readBytesUntil() etc. can be used.

Changes to the inode (size, extents) are kept in the File object and are written by flush() or close(), which is also called by the destructor. Don't write to the same file through two File objects at the same time.
