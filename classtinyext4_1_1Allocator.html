Detailed Description

Memory allocator that prefers PSRAM (SPI RAM) when the board provides it: ESP32 (heap_caps_malloc with MALLOC_CAP_SPIRAM) and RP2350 with PSRAM (pmalloc). Otherwise and when PSRAM is exhausted the normal heap is used. Allocated memory is zeroed.

Subclass it and pass it to Ext4FS::setAllocator() / RamIO to place the buffers somewhere else.
