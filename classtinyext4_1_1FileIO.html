Detailed Description

Block device backed by a plain host OS file (a disk image), for the desktop/native build only. Unlike RamIO, the backing store survives past the lifetime of one process: the image can be created with mkfs.ext4 and inspected or cross-checked with ordinary OS tools (e2fsck, debugfs, dumpe2fs, a loopback mount, ...).

TinyEXT4 does not format: an image that does not exist yet is created empty (sparse) and must be formatted with mkfs.ext4 before mounting. With sectorCount = 0 the size is taken from the existing file. Images that are not writable are opened read only.
